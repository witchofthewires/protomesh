# Project Samsara
The Protomesh Collective is pleased to be a supporter of efforts by the Pitt Robotics and Automation Society to build an autonomous solar-powered cargo drone, and has donated the following to support those efforts:

- Holybro X500 V2 Frame Kit
- Raspberry Pi Zero 2W
- 25cm nickel strip

For more information, see the official [SamsaraProject](https://github.com/Team-Volcris/SamsaraProject.git) Github repo.
