## Changelog
### v1.1.3 (released )
- Updated case design to include clip ridge, to prevent case from bulging when shut
### v1.1.2 (released )
- Updated case design to physically clip shut
### v1.1.1 (released )
- Replaced adhesive-joined battery pack design (v1.0.0 design utilized spring pressure inside a single rigid case mainbody, an approach which is not compatible with v1.1.0 case design) with spot-welded battery packs
### v1.1.0 (released )
- Upgraded board from Heltec ESP-32V3, requiring new case design
### v1.0.0 (released )
- Initial working build
